
# DLRC Creator

A browser-based tool for creating, synchronizing, and editing Duet LRC (DLRC) lyric files.

## Current development phase

Phase 1 — Foundation.

### Features

- Responsive desktop and mobile interface.
- Local audio file selection and drag-and-drop.
- Audio playback, seeking, and playback-speed controls.
- Lyrics input with automatic non-empty line counting.
- Local browser playback without uploading audio to a server.
- Modular JavaScript structure.

### Planned features

**Phase 2 — Lyric synchronization and DLRC editor**
- Timestamp lyrics during playback.
- Edit and adjust individual timestamps.
- Keyboard shortcuts.
- Singer-column declarations and color tags.
- DLRC metadata editing.

**Phase 3 — Output and validation**
- Live DLRC source preview.
- DLRC syntax validation.
- Import existing DLRC files.
- Download generated `.dlrc` files.

**Phase 4 — Responsive polish**
- Desktop and mobile workflow refinements.
- Touch-friendly synchronization controls.
- Accessibility and usability testing.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Select an audio file and enter lyrics.

For local development, you can also use the Live Server extension in Visual Studio Code.

## Privacy

Audio files are processed locally in the browser. This foundation does not upload audio to a server.
